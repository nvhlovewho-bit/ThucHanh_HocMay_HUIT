# Thực hành Học máy - HUIT

Repository lưu trữ các bài thực hành và bài tập môn Học máy.

## Nội dung

| Tuần | Chủ đề | Nội dung |
|---|---|---|
| 1 | Regression | Linear Regression, Logistic Regression và bài tập thực hành |
| 2 | KNN & SVM | Phân lớp, hồi quy và thực nghiệm mô hình |

## Công cụ sử dụng
- Python
- Google Colab
- NumPy, Pandas
- Matplotlib, Scikit-learn

## Cách sử dụng

Mở file Notebook `.ipynb` bằng Google Colab để xem code, nội dung giải thích và chạy lại các bài thực hành.
